ROUE 2TNX DISCORD PRO

FONCTIONS
- 7 personnages issus de l'image fournie.
- Animation de roue fluide.
- Tirage aléatoire avec crypto.getRandomValues().
- Sons de roulette + son de victoire.
- Confettis.
- Mode élimination : le gagnant est automatiquement désactivé.
- Activation/désactivation manuelle de chaque personnage.
- Noms modifiables.
- Historique des 50 derniers tirages.
- Plein écran.
- Message prêt à copier dans Discord.
- Partage natif vers Discord sur téléphone quand le navigateur le permet.
- Création d'une carte PNG du gagnant en 1200x675, idéale à poster dans Discord.
- Installation PWA lorsqu'elle est hébergée en HTTPS.
- Fonctionnement hors connexion après installation.

UTILISATION LOCALE
1. Décompresser le ZIP.
2. Ouvrir index.html dans Chrome, Edge ou Firefox.
3. Cliquer sur « TOURNER LA ROUE ».

UTILISATION DANS DISCORD
Discord n'exécute pas directement une application HTML envoyée en pièce jointe.
Pour avoir un vrai lien cliquable utilisable par tous :
- héberger le contenu de ce dossier sur GitHub Pages, Netlify ou Cloudflare Pages ;
- partager ensuite l'adresse du site dans un salon Discord.

Aucun serveur ni base de données n'est requis.
Les noms, réglages et historique restent dans le navigateur de chaque utilisateur.
